# Plantilla de Question Set

`question-set-616.h5p` es una copia estática del ejemplo de H5P distribuido en <https://h5p.org/sites/default/files/question-set-616_2.h5p>, enlazado desde <https://h5p.org/node/1234228>. La plantilla contiene bibliotecas H5P y metadatos de terceros; sus archivos `library.json` describen los autores y licencias disponibles. Question Set y Multiple Choice declaran licencia MIT. El empaquetador conserva las bibliotecas y reemplaza completamente `content/` y los metadatos de la actividad; no exporta el contenido ni los medios del ejemplo.

La plantilla sirve como dependencia de entrada, no como archivo de salida generado. Antes de actualizarla hay que comprobar las versiones de bibliotecas, sus licencias y la compatibilidad del esquema generado con la plantilla nueva.
